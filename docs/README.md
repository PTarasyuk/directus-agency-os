# AgencyOS Documentation

Технічна документація для AgencyOS.

## Запуск документації

### Development

```bash
pnpm docs:dev
```

Відкрийте [http://localhost:5173](http://localhost:5173)

### Build

```bash
pnpm docs:build
```

### Preview

```bash
pnpm docs:preview
```

## Структура документації

- `/guide` — посібник для початківців
- `/architecture` — архітектура проекту
- `/modules` — модуль Directus
- `/components` — компоненти
- `/layers` — Nuxt Layers
- `/api` — API endpoints
- `/deployment` — розгортання

## Редагування

Всі файли документації знаходяться в `docs/` директорії.

Формат: Markdown з VitePress extensions.
